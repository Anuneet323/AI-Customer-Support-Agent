# Raw Data Directory

Place the raw Twitter Customer Support dataset (`twcs.csv`) in this directory if re-running data extraction from scratch:
https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter

Note: The curated data splits (`train.jsonl`, `val.jsonl`, `held_out.jsonl`) and the 200-example golden evaluation set (`golden_set.jsonl`) are already provided and ready to use without needing the original 500MB CSV file.
